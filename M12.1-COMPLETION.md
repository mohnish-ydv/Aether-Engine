# M12.1 Completion — Real-Web Rendering Rescue

M12.1 is a cumulative corrective sprint based on actual installed-device screenshots. It preserves M1–M12 and targets the gap between an operational browser shell and coherent rendering of server-delivered production pages.

## Completed

- Standards-oriented HTML user-agent defaults
- External and imported stylesheet pipeline with security and URL resolution
- Logical CSS and legacy WebKit Flexbox compatibility mappings
- Better replaced-element/form intrinsic sizing
- Responsive image source fallback
- Inline/native SVG path foundation
- Four new repository tests and an 18/18 executable compatibility harness
- Updated version, UI identity, CI artifacts, reports and source audit

## Not claimed

This milestone does not claim Chromium parity or complete modern JavaScript, CSS Grid, SVG, web fonts, animations and accessibility. It materially repairs the screenshot failure class and establishes testable real-web loading foundations without replacing the engine with Android WebView.
